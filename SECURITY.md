# Sicherheit

## Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über GitHub:
im Repository unter **Security → Report a vulnerability**
(<https://github.com/joeMJ/remotejoe/security/advisories/new>).

Hilfreich sind:

- die Fassung von remotejoe (Hilfe → Über remotejoe) und das Betriebssystem,
- eine kurze Beschreibung der Lücke und ihrer Auswirkung,
- Schritte zum Nachstellen, wenn möglich mit einem Beispiel ohne echte Zugangsdaten.

Bitte keine Kennwörter, Schlüsseldatenbanken oder Daten echter Systeme mitschicken.

## Unterstützte Fassungen

Sicherheitskorrekturen gibt es nur für die jeweils neueste veröffentlichte Fassung. Ältere Fassungen bitte zuerst
aktualisieren (Hilfe → Nach Updates suchen).

## Ablauf

Meldungen werden vertraulich bearbeitet. Feste Reaktionszeiten und eine Belohnung (Bug-Bounty) gibt es nicht. Ist eine
Lücke behoben, nennen die Releasenotes der Fassung die Korrektur.

---

## Reporting a vulnerability (English)

Please do **not** open a public issue. Report vulnerabilities privately via GitHub:
**Security → Report a vulnerability** in this repository. Only the latest release receives security fixes.
